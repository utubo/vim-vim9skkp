INTRODUCTION					*vim9skkp-introduction*

*vim9skkp* は、SKK日本語入力をVim9 scriptとポップアップウインドウで実装した
実験的なプラグインです

ポップアップウインドウを使うことで以下を実現しています
・確定するまでバッファが汚れない
・キーマッピングは最低限(有効、無効、トグルだけ)

Latest version:
https://github.com/utubo/vim-vim9skkp.vim


==============================================================================
INSTALLATION					*vim9skkp-instllation*

辞書をダウンロードする >
	cd ~
	wget http://openlab.jp/skk/dic/SKK-JISYO.L.gz
	gunzip -f SKK-JISYO.L.gz

お好きな方法でvim9skkpにパスを通す
(以下はpack以下に置いて読み込ませる例) >
	mkdir -p ~/.vim/pack/foo/start
	cd ~/.vim/pack/foo/start
	git clone https://github.com/utubo/vim-vim9skkp.git

==============================================================================
USAGE						*vim9skkp-usage*

挿入モードやコマンドモードにて`<C-j>`で起動します
入力形式は基本的によくあるSKKと同様です

以下はちょっと特殊です

- ひらがなモードまたはカタカナモードで以下の変換が用意されています
	`z<Space>` 全角スペース
	`z.` …
	`z/` ・
	`z[` 「
	`z]` 」
	`zh` ←
	`zj` ↓
	`zk` ↑
	`zl` →

- 見出しモードまたはスティッキーシフトでシフトが有効なときに
  先頭に大文字を入力するとabbrevモードになります

VARIABLES					*vim9skkp-variables*

g:vim9skkp					*g:vim9skkp*
	各種設定のdictionaryです

	jisyo
		辞書ファイルのパスの配列
		`ファイル名:文字コード`の形式
		ワイルドカードはvim9skkpの初回起動時に展開します
		NOTE:
			辞書はキャッシュされます(後述の他の辞書設定も同様)
			vim9skkp起動後に辞書ファイルを置いた場合は後述の
			|:Vim9skkpReloadJisyo|を実行してください
	jisyo_fuzzy
		候補を曖昧検索する辞書ファイルのパスの配列
		あまり大きなファイルを指定すると重くなると思います
	jisyo_user
		ユーザー辞書ファイルのパス
	jisyo_recent
		「最後に実行した変換」辞書ファイルのパス
		「最後に実行した変換」辞書はvimを閉じるときに保存されます
	recent_limit
		「最後に実行した変換」辞書の最大件数
	recent_per_yomi
		「最後に実行した変換」辞書の一つの読みに対する最大候補数
	fuzzy_limit
		曖昧検索の検索上限
	marker_okuri
		送り仮名のマーカーです
	mode_label
		現在の入力モードを表す文字です
	mode_display
		入力モードの表示形式です
		"|popup|": カーソルの下にポップアップで表示します
		"|cursor|": カーソル位置に表示します
		"|none|": 表示しません
	popup_maxheight
		変換候補の最大表示行数です
	cands_popup_options
		変換候補のポップアップウィンドウのオプションです
		詳細は|popup_create-options|
		変換候補に枠を付けたい場合に利用できます
	mode_popup_options
		モード表示のポップアップウィンドウのオプションです
	main_popup_options
		入力文字列のポップアップウィンドウのオプションです
	search_limit
		候補探索の試行上限です
	keymap
		キーマップです
		文字列または文字列の配列で指定します
		割り当てできるのは1ストロークまでです
		配列で複数のキーを割り当てられます
		e.g.) >
			# AまたはBでトグル
			g:vim9skkp.keymap.toggle = ['A', 'B']
<
		toggle
			vim9skkpのオンオフをトグルします
			全角英数モードやabbrevモードの場合は、ひらがなモードへ切り替えます
		enable
			vim9skkpを有効にします
		disable
			vim9skkpを無効にします
		terminal
			terminalに入力するための入力プロンプトを表示します
		kana
			カナモードをトグルします
		hankaku
			半角カナモードをトグルします
		alphabet
			全角英数モードをトグルします
		abbr
			abbrevモードをトグルします
		hira
			ひらがなモードへ切り替えます
		select
			選択モードへ切り替えます
			既に選択モードの場合は、次の候補を選択します
			見出しモードでない場合は無効です
		next
			次の候補を選択します
		prev
			前の候補を選択します
		shortcut
			候補選択のショートカットキーです
		select_kata
			カタカナで確定します(選択モード)
		select_direct
			直接入力で確定します(選択モード)
		select_upper
			大文字で確定します(選択モード)
		select_lower
			小文字で確定します(選択モード)
		commit
			変換を確定します
		delete
			選択中の候補をユーザー辞書と変換履歴から
			削除します
		userjisyo
			変換候補が見つからなかった場合と同様に
			ユーザー辞書登録のプロンプトを起動します
		cancel
			以下の通りです
			選択モード中: 変換をキャンセルし見出しモードに移行
			見出しモード中: 見出しモードのまま入力を削除
			入力無し: vim9skkpをクローズ
		sticky_shift
			所謂スティッキーシフトです
		left
			カーソルを左へ移動
		right
			カーソルを右へ移動
	roman_table
		ローマ字入力の追加・上書き設定です
		例: `{ kn: 'かん' }`
	roman_abbrev
		roman_tableと似ていますが、こちらは確定まで実行します
		sticky_lockが|true|な場合にちょっと便利です
		例: `{ mt: 'ました。', kj: '漢字' }`
	sticky_lock
		|true|の場合、見出しモードが基準になります
		具体的には以下のときに即座に見出しモードに移行します
		- vim9skkpが有効になったとき
		- 変換を確定/キャンセルした後
		- vim9skkp.keymap.toggleでひらがなモードに切り替わったとき
		NOTE: vim9skkp.keymap.kanaなどで入力文字種を変更したときは
		ロック対象外です
	auto_commit_regex:
		見出しモードで入力値がこの正規表現にマッチしたとき
		即座に確定します
	auto_suggest_regex:
		見出しモードで入力値がこの正規表現にマッチしたとき
		変換を開始します
	abbr_with_shift
		見出しモード中に大文字入力でabbrevモードへ切り替えます
	hide_cursor
		trueの場合、vim9skkp起動中にカーソルを非表示にします
		vi9skkp終了後にカーソルが表示されなくなってしまう場合は
		falseにしてみてください
	getcurpos
		画面上のカーソル位置を返却するfuncrefです
		ポップアップなどの表示位置を微調整したい場合は
		以下の関数を用意しカーソル位置を返却してください
		引数pos.lineとpos.colはvim9skkpが算出したカーソル位置です >
			foo(pos: any): any
<
	terminal_prompt
		terminalに入力するための入力プロンプトです
	predict
		予測入力を有効にします
	predict_title
		予測入力ポップアップのタイトルです
	dumpsize
		デバッグ用です。ポップアップに飛んできた入力を
		このサイズの分だけ保存します。

	デフォルトは以下です >
	{
	  jisyo: ['~/SKK-JISYO.L:EUC-JP', '~/SKK-JISYO.*.utf8:UTF8'],
	  jisyo_fuzzy: [ '~/SKK-JISYO.emoji.utf8' ],
	  jisyo_user: '~/VIM9SKKP-JISYO.user',
	  jisyo_recent: '~/VIM9SKKP-JISYO.recent',
	  recent_limit: 1000,
	  recent_per_yomi: 1,
	  fuzzy_limit: 10,
	  marker_okuri: '*',
	  mode_label: {
	    off: '_A',
	    hira: 'あ',
	    kata: 'ア',
	    hankaku: 'ｶﾅ',
	    alphabet: 'Ａ',
	    abbr: 'ab',
	    midasi: '▽',
	  },
	  mode_display: 'popup',
	  cands_popup_options: {},
	  mode_popup_options: {},
	  main_popup_options: {},
	  search_limit: 100,
	  keymap: {
	    enable: [],
	    disable: [],
	    toggle: "\<C-j>",
	    terminal: "\<C-j>",
	    hira: [],
	    kata: 'q',
	    hankaku: "\<C-q>",
	    alphabet: 'L',
	    abbr: '/',
	    select: [' '],
	    next: "\<Tab>",
	    prev: ["\<S-Tab>", 'x'],
	    shortcut: '.123456789'->split('\zs'),
	    select_kata: [],
	    select_direct: [],
	    select_upper: [],
	    select_lower: [],
	    commit: "\<CR>",
	    cancel: "\<C-g>",
	    delete: "\<C-d>",
	    userjisyo: "\<C-u>",
	    sticky_shift: 'Q',
	    left: "\<Left>",
	    right: "\<Right>",
	  },
	  roman_table: {},
	  roman_abbrev: {},
	  sticky_lock: false,
	  auto_commit_regex: '[ をヲ、。「」]',
	  auto_suggest_regex: '*[っッ]\?[^a-zA-Zっッ]$',
	  abbr_with_shift: false,
	  getcurpos: vim9skkp#Nop,
	  hide_cursor: true,
	  terminal_prompt: 'terminalに入力: ',
	  predict: true,
	  predict_title: '予測入力',
	  dumpsize: 0,
	}
<
Note:  カスタマイズする際は、デフォルトから変更したい項目だけをセットすれば
よいです >
	g:vim9skkp = {
	  keymap: {
	    sticky_shift: ';',
	  }
	}
<
g:vim9skkp_status				*g:vim9skkp_status*
	現在のvim9skkpの状態をあらわすdictionaryです
	statuslineなどにお使いください
	以下の様にユーザーイベントを利用するとリアルタイムで更新できます >

		autocmd User Vim9skkStatusChanged redraws!
<
	active
		vim9skkpが起動している場合true、
		それ以外の場合false
	mode_label
		見出しモードならg:vim9skkp.mode_label.midasi
		それ以外の場合g:vim9skkp.mode_labelに対応する文字列
	mode
		入力モード(見出しモードを考慮しない)
		g:vim9skkp.mode_labelに対応する文字列
	midasi
		見出しモードならtrue、それ以外ならfalse
	sticky_shift
		スティッキーシフトによってシフトが有効ならtrue、
		それ以外ならfalse
	cand_winid
		変換候補ポップアップのウインドウIDです

g:vim9skkp_exception				*g:vim9skkp_exception*
	vim9skkpで最後に発生した例外です
	CursorMovedなどで例外が発生したとき、操作不能にならないように
	例外をスローする代わりにこの変数に代入しています

------------------------------------------------------------------------------
COMMANDS					*vim9skkp-commands*

:Vim9skkpTerminalInput				*:Vim9skkpTerminalInput*
	terminalに入力するための入力プロンプトを表示します

:Vim9skkpReloadJisyo				*:Vim9skkpReloadJisyo*
	辞書を再読み込みします

:Vim9skkpRegisterToUserJisyo [{読み}]		*:Vim9skkpRegisterToUserJisyo*
	ユーザー辞書に登録します

------------------------------------------------------------------------------
FUNCTIONS					*vim9skkp-functions*

vim9skkp#Enable()				*vim9skkpEnable*
	vim9skkpを有効にします

vim9skkp#Disable()				*vim9skkpDisable*
	vim9skkpを無効にします

vim9skkp#Toggle()				*vim9skkpToggle*
	有効・無効を切り替えます

vim9skkp#ReadJisyo({パス})			*vim9skkpReadJisyo*
	パスで指定した辞書を読み込み、
	{ line: list<string>, enc: string }
	をreturnします

vim9skkp#Dump()					*vim9skkpDump*
	入力履歴を表示します
	Note: 事前にg:vim9skkp.dumpsizeを設定してください

------------------------------------------------------------------------------
EVENTS						*vim9skkp-events*

Vim9skkpStatusChanged				*Vim9skkpStatusChanged*
	|g:vim9skkp_status|が変更されたときに発火します

Vim9skkpCandPopup						*Vim9skkpCandPopup*
	変換候補が表示されたときに発火します

------------------------------------------------------------------------------
HIGHLIGHTS					*vim9skkp-highlights*

Vim9skkpCursor		カーソル

Vim9skkp		入力文字列
Vim9skkpBlur		非アクティブ時(ユーザー辞書登録が起動)

Vim9skkpMode		モード表示の色

Vim9skkpCand		変換候補
Vim9skkpCandExtra	変換候補の補足
Vim9skkpCandShortCut	変換候補のショートカットキー

Note:  ポップアップを使っているのでハイライトのベースはPMenuになります

	vim9skkpを有効にします

<Plug>(vim9skkp-disable)
	vim9skkpを無効にします

<Plug>(vim9skkp-terminal)
	terminalに入力するための入力プロンプトを表示します
